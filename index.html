03 Práctica guiada

Antes de opinar, aprende a mirar

Usaremos el Café Buen Día para practicar tres movimientos: observar señales, relacionarlas con dimensiones y decidir qué evidencia falta.

Caso · Café Buen Día

Las ventas aumentaron. El dueño está preocupado.

El café lleva tres años funcionando y tiene buenas evaluaciones.

  • El dueño realiza las compras y conoce de memoria a los proveedores.
  • Los precios se fijaron hace más de un año.
  • Cada trabajador prepara algunos productos de manera diferente.
  • El inventario se revisa cuando falta algo.
  • No hay claridad sobre el margen de cada producto.
  • Las ventas se registran, pero rara vez se analizan.
  • Si el dueño falta, varias decisiones quedan pendientes.

¿Qué señales requieren atención?

Marca aquello que podría indicar una necesidad de gestión.

Las señales no son solo “cosas negativas”. Incluso un aumento de ventas puede ser relevante si no sabemos qué está ocurriendo con costos, márgenes o capacidad operativa.

¿Qué dimensiones aparecen?

Selecciona las que te parecen directamente involucradas.

Varias dimensiones se cruzan. Este es justamente el punto: un problema de gestión rara vez pertenece a una sola “caja”.

¿Qué información falta?

Elige qué revisarías antes de recomendar una solución.

Diagnosticar no es opinar: es reunir evidencia suficiente para comprender qué ocurre antes de decidir qué hacer.
Secuencia

Observar → relacionar → preguntar

Esta lógica volverá a aparecer durante todo el curso.

Evita

Saltarte al consejo

“Compra un software” o “haz publicidad” son soluciones, no diagnósticos.

04 Conceptualización

Transforma una impresión en una pregunta de gestión

Ahora ponemos nombre a lo que acabas de hacer con el caso: pasar del síntoma a una investigación más útil.

Modelo de análisis

Síntoma → preguntas → evidencia → problema

Un síntoma es lo que vemos o sentimos. El problema se formula cuando contamos con evidencia suficiente para explicar qué necesita intervención.
