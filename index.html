02 Mapa de funcionamiento

Construye el recorrido real de un cliente

No uses el proceso “ideal”. Escribe lo que efectivamente suele ocurrir. Puedes agregar, borrar y mover pasos.

Recorrido actual

Ejemplo

“Me escriben por WhatsApp → respondo disponibilidad → cotizo → confirmo → realizo el servicio → transfieren → anoto en una planilla”.

¿Qué estás haciendo aquí?

Estás transformando una actividad cotidiana en un mapa de proceso, aunque todavía no usemos formalmente ese concepto.

Observa

Los problemas suelen estar entre pasos

01 Activación de problema

Las ventas aumentaron. ¿Entonces el negocio está mejor?

Antes de presentar un modelo, vamos a enfrentarnos a una situación que obliga a mirar más de una cosa al mismo tiempo.

Caso · Café Buen Día

Más clientes, más trabajo… y menos tranquilidad

El café lleva tres años funcionando. Durante el último año aumentaron las ventas y las evaluaciones de clientes siguen siendo buenas.

  • El dueño compra y conoce de memoria a los proveedores.
  • Los precios no se revisan hace más de un año.
  • Cada trabajador prepara algunos productos de manera distinta.
  • El inventario se revisa cuando falta algo.
  • No hay claridad sobre el margen de cada producto.
  • Las ventas se registran, pero rara vez se analizan.
  • Si el dueño falta, varias decisiones quedan pendientes.

Primera reacción

No busques todavía “la respuesta correcta”. Registra qué te llama la atención.

¿Podemos decir que funciona bien?

Una respuesta útil no depende de elegir “sí” o “no”, sino de reconocer qué información necesitamos antes de evaluar el negocio.
Propósito

Crear una necesidad de análisis

El modelo aparece después de que el caso demuestra que mirar solo las ventas no basta.

Recuerda

Tu negocio ya está aquí

Más adelante aplicarás el mismo criterio a tu propia fotografía.

04 Herramienta de pensamiento

No compres una solución antes de entender el problema

Practica cómo transformar una necesidad expresada en preguntas y evidencia útil antes de decidir una intervención.

Secuencia de análisis

Síntoma → preguntas → evidencia → problema

El síntoma es lo que vemos o sentimos. El problema se formula cuando la evidencia permite explicar qué necesita intervención.

1Síntoma
2Preguntas
3Evidencia
4Problema
Síntoma“Necesito vender más”
